# Lie rings in Lean 4

This package develops foundational results about Lie algebras over commutative rings, with an
emphasis on Lie rings (the case `R = ℤ`). It uses mathlib's definitions of Lie algebras and
universal enveloping algebras.

## Build

From this directory run:

```bash
lake build
```

The project is pinned to Lean 4 and mathlib `v4.29.0`. The library contains no `sorry`
declarations.

## Main proven results

### PBW and the canonical embedding

- For an Abelian Lie algebra, PBW is a basis-free algebra equivalence:
  `PBW.abelianEquivSymmetric R L : UEA R L ≃ₐ[R] SymmetricAlgebra R L`.
- If the underlying module has an ordered basis, ordered PBW monomials span the enveloping
  algebra: `PBW.orderedPBWMap_surjective R L ι b`.
- A `PBW.TriangularRepresentation R L ι b` proves the full ordered-basis statement
  `PBW.FreeModulePBW R L ι b` (the ordered PBW map is bijective), and hence the canonical
  embedding. The general non-Abelian ordered-basis PBW theorem is not claimed without this
  representation hypothesis.
- Over `ℤ`, every Lie ring embeds canonically, without a basis or auxiliary parameter:

```lean
PBW.canonicalMap_injective_int L :
  Function.Injective (UniversalEnvelopingAlgebra.ι ℤ : L → UEA ℤ L)
```

### Dimension subrings and lower central series

With conventional positive indexing (`δₙ = dimensionSubring ℤ L n` and
`γₙ = lowerCentralSeries ℤ L (n - 1)`), the following are proved:

- `UEA.quotientEquivLieIdeal R L I`: `U(L/I) ≃ₐ[R] U(L)/⟨I⟩`, for every Lie ideal `I`.
- `dimensionSubring_two_eq_lowerCentralSeries_one`: `δ₂(L) = γ₂(L)` over every commutative
  base ring.
- `dimensionSubring_three_eq_lowerCentralSeries_two`: `δ₃(L) = γ₃(L)` for every Lie ring.
- `FreeLieDimension.dimensionSubring_succ_eq_lowerCentralSeries`: for
  `F = FreeLieAlgebra ℤ X`, `δₙ(F) = γₙ(F)` in every positive degree.
- `dimensionSubring_bracket_eq_lowerCentralSeries_of_pos`:
  `[δₙ(L), L] = γₙ₊₁(L)` for `1 ≤ n`.
- `bracket_dimensionSubring_le_lowerCentralSeries_of_pos`:
  `[δₘ(L), δₙ(L)] ⊆ γₘ₊ₙ(L)` for `1 ≤ m, 1 ≤ n`.
- `UEA.actionSubmodule_augmentationIdeal_pow_eq_lcs`:
  `A · 𝜔(L)^n = [A,ₙL]` for a Lie submodule `A`.

The degree-five theorem currently exported by the library is the standing-reduction result. A
`DegreeFive.StandingReductionData L` consists of:

1. a finite underlying Lie ring `L`;
2. a 2-primary additive group (`IsPGroup 2 (Multiplicative L)`);
3. nilpotency class at most three, `lowerCentralSeries ℤ L 3 = ⊥` (equivalently `γ₄(L) = 0`);
4. an additive equivalence `γ₃(L) ≃+ ZMod (2^k)` for some `k` (so `γ₃(L)` is cyclic of
   2-power order).

Under exactly these hypotheses,
`DegreeFive.StandingReductionData.dimensionSubring_five_eq_bot` proves `δ₅(L) = 0`. No unconditional
general theorem `δ₅(L) ⊆ γ₄(L)` is exported yet.

## Definitions and how to use them

For downstream files, `import LieRings` imports the public library. Focused imports are also
available; the main definitions are located as follows.

| Mathematical object | Lean declaration | File |
|---|---|---|
| `U_R(L)` | `UEA R L` (an abbreviation for mathlib's `UniversalEnvelopingAlgebra`) | `UniversalEnveloping/Basic.lean` |
| canonical map `ι : L → U_R(L)` | `UniversalEnvelopingAlgebra.ι R` | `UniversalEnveloping/Basic.lean` |
| augmentation `ε` and augmentation ideal `𝜔(L)` | `UEA.augmentation R L`, `UEA.augmentationIdeal R L` | `UniversalEnveloping/Basic.lean` |
| dimension subring `δₙ(L)` | `dimensionSubring R L n` | `DimensionSubring/Basic.lean` |
| lower central term `γₙ₊₁(L)` | `lowerCentralSeries R L n` | `DimensionSubring/Centrality.lean` |
| ideal generated by a Lie ideal | `UEA.idealOfLieIdeal R L I` | `UniversalEnveloping/Quotient.lean` |
| enveloping-algebra action | `UEA.representation R L M` | `UniversalEnveloping/Adjoint.lean` |
| ordered PBW map | `PBW.orderedPBWMap R L ι b` | `PBW/FreeModuleStatement.lean` |
| standing reduction data | `DegreeFive.StandingReductionData L` | `DimensionSubring/DegreeFive/StandingReduction.lean` |

Mathlib numbers the lower central series from zero, so
`lowerCentralSeries R L 0 = γ₁(L) = L`. For example:

```lean
import LieRings.DimensionSubring.DegreeThree

example (L : Type*) [LieRing L] :
    dimensionSubring ℤ L 3 = lowerCentralSeries ℤ L 2 :=
  dimensionSubring_three_eq_lowerCentralSeries_two L
```

The directory [`LieRings/Examples`](LieRings/Examples) contains short, compiled examples for
PBW, quotients, dimension centrality, and free Lie rings.
