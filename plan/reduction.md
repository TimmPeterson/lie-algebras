Да, такая редукция корректна. Помимо включения (2\delta _4\subseteq \gamma _4), в ней существенно используется равенство
[
\delta _3(L)=\gamma _3(L).
]
У Бартольди–Пасси это соответственно теорема 4.5 и следствие 4.10. 

Ниже (\varpi(L)) обозначает идеал аугментации в (U(L)), а
[
\delta_n(L)=\iota_L^{-1}\bigl(\varpi(L)^n\bigr),
]
где (\iota_L\colon L\to U(L)) — канонический гомоморфизм. Такая запись через полный прообраз удобна, поскольку (\iota_L) не обязана быть вложением.

## Предложение о редукции

Предположим, что для всякого конечного (2)-примарного кольца Ли (M) класса нильпотентности (3), у которого (\gamma _3(M)) циклична, выполнено
[
\delta _5(M)=0.
]
Тогда для всякого кольца Ли (L) над (\mathbb Z) выполнено
[
\delta _5(L)\subseteq \gamma _4(L).
]

Докажем это от противного.

### 1. Функториальность размерных подколец

Для любого гомоморфизма колец Ли
[
f\colon L\longrightarrow M
]
выполнено
[
f\bigl(\delta_n(L)\bigr)\subseteq \delta_n(M).
]

Действительно, (f) индуцирует гомоморфизм ассоциативных алгебр
[
U(f)\colon U(L)\longrightarrow U(M),
]
для которого
[
U(f)\circ\iota_L=\iota_M\circ f.
]
Кроме того,
[
U(f)\bigl(\varpi(L)\bigr)\subseteq\varpi(M),
]
а потому
[
U(f)\bigl(\varpi(L)^n\bigr)\subseteq\varpi(M)^n.
]
Следовательно, если (x\in\delta_n(L)), то
[
\iota_M(f(x))
=U(f)(\iota_L(x))
\in\varpi(M)^n,
]
то есть (f(x)\in\delta_n(M)).

В частности, при переходе к факторкольцу образ элемента из (\delta_n) снова принадлежит (\delta_n). Равенство размерных подколец при факторизации нам не требуется.

Для сюръективного гомоморфизма (q\colon L\twoheadrightarrow M) также имеем
[
q(\gamma_n(L))=\gamma_n(M).
]
Это немедленно следует индукцией из
[
q([X,L])=[q(X),M].
]
Поэтому для идеала (I\triangleleft L)
[
\gamma_n(L/I)=\frac{\gamma_n(L)+I}{I}.
]

### 2. Элемент из (\delta _5(L)) имеет конечно порождённый свидетель

Нам понадобится следующий факт.

**Лемма.** Если (x\in\delta_n(L)), то существует конечно порождённое подкольцо Ли (A\subseteq L), содержащее (x), такое что
[
x\in\delta_n(A).
]

**Доказательство.** Рассмотрим направленную систему всех конечно порождённых подколец Ли (A\subseteq L), содержащих (x). Их направленный предел равен (L).

Функтор универсальной обёртывающей алгебры является левым сопряжённым, поэтому он сохраняет направленные пределы:
[
U(L)\cong\varinjlim_A U(A).
]

Поскольку (\iota_L(x)\in\varpi(L)^n), существуют конечное число элементов
[
u_{jk}\in\varpi(L)
]
таких, что
[
\iota_L(x)=\sum_j u_{j1}u_{j2}\cdots u_{jn}.
]
Все (u_{jk}) приходят из некоторой общей стадии (U(A)). Их прообразы можно взять в (\varpi(A)), поскольку все отображения (U(A)\to U(L)) согласованы с аугментациями. Таким образом, существует
[
v\in\varpi(A)^n
]
образ которого в (U(L)) равен (\iota_L(x)).

В направленном пределе равенство двух элементов выполняется уже на некоторой достаточно большой стадии. Следовательно, после замены (A) на большее конечно порождённое подкольцо имеем в (U(A))
[
\iota_A(x)=v\in\varpi(A)^n.
]
Значит, (x\in\delta_n(A)). (\square)

Этот аргумент через направленный предел нужен для строгости: нельзя без дополнительного обоснования считать отображение (U(A)\to U(L)) инъективным.

---

Теперь предположим, что утверждение теоремы неверно. Тогда существуют кольцо Ли (L) и элемент
[
x\in\delta_5(L)\setminus\gamma_4(L).
]

По предыдущей лемме можно выбрать конечно порождённое подкольцо Ли (A\subseteq L), содержащее (x), такое что
[
x\in\delta_5(A).
]
При этом
[
\gamma_4(A)\subseteq\gamma_4(L),
]
поэтому
[
x\notin\gamma_4(A).
]

### 3. Переход к классу нильпотентности (3)

Положим
[
B=A/\gamma_4(A)
]
и обозначим образ (x) в (B) через (b).

По функториальности
[
b\in\delta_5(B).
]
Кроме того, (b\neq0), поскольку (x\notin\gamma_4(A)), и
[
\gamma_4(B)=0.
]

Так как размерная фильтрация убывает,
[
\delta_5(B)\subseteq\delta_3(B).
]
Используя (\delta_3(B)=\gamma_3(B)), получаем
[
0\neq b\in\gamma_3(B).
]
Следовательно,
[
\gamma_3(B)\neq0,\qquad \gamma_4(B)=0,
]
то есть (B) имеет класс нильпотентности ровно (3).

Далее,
[
b\in\delta_5(B)\subseteq\delta_4(B).
]
По известному включению
[
2\delta_4(B)\subseteq\gamma_4(B)=0
]
имеем
[
2b=0.
]
Поскольку (b\neq0), элемент (b) имеет порядок ровно (2).

### 4. Переход к конечному (2)-примарному фактору

Кольцо (B) конечно порождено как кольцо Ли и нильпотентно класса (3). Поэтому его аддитивная группа конечно порождена.

Действительно, если (B) порождено элементами (b_1,\dots,b_d), то как абелева группа оно порождается значениями лиевых слов от этих элементов. Все лиевы слова степени не меньше (4) равны нулю, а слов степеней (1,2,3) имеется лишь конечное число. Например, достаточно взять элементы
[
b_i,\qquad [b_i,b_j],\qquad [[b_i,b_j],b_k].
]

По теореме о структуре конечно порождённых абелевых групп можно, только как абелеву группу, записать
[
B_{\mathrm{add}}
\cong
\mathbb Z^r\oplus T_{(2)}\oplus T_{(2')},
]
где (T_{(2)}) — конечная (2)-примарная группа, а (T_{(2')}) — конечная группа нечётного порядка.

Поскольку (b) имеет порядок (2), в этом разложении
[
b\in T_{(2)},\qquad b\neq0.
]

Выберем (N\geq1) так, чтобы
[
2^N T_{(2)}=0.
]
Умножение на (2^N) является автоморфизмом группы (T_{(2')}), поэтому
[
2^NB
\cong
2^N\mathbb Z^r\oplus 0\oplus T_{(2')}.
]
В частности,
[
b\notin 2^NB.
]

Аддитивная подгруппа (2^NB) является идеалом кольца Ли, поскольку
[
[2^Nu,v]=2^N[u,v]\in2^NB.
]

Положим
[
C=B/2^NB
]
и обозначим образ (b) через (c). Тогда:

[
c\neq0,
\qquad
c\in\delta_5(C)
]
по функториальности, а аддитивная группа (C) имеет вид
[
C_{\mathrm{add}}
\cong
(\mathbb Z/2^N\mathbb Z)^r\oplus T_{(2)}.
]
Следовательно, (C) конечно и (2)-примарно.

Также
[
\gamma_4(C)=0,
\qquad
0\neq c\in\gamma_3(C),
]
поскольку (c) является образом элемента (b\in\gamma_3(B)). Поэтому (C) всё ещё имеет класс нильпотентности ровно (3).

### 5. Переход к циклической (\gamma_3)

Положим
[
G=\gamma_3(C).
]
Это конечная абелева (2)-группа, и
[
0\neq c\in G.
]

По теореме о структуре конечных абелевых (2)-групп существует разложение
[
G\cong
\mathbb Z/2^{e_1}\mathbb Z\oplus\cdots\oplus
\mathbb Z/2^{e_s}\mathbb Z.
]
Хотя бы одна координата элемента (c) в этом разложении ненулевая. Выберем индекс (j), для которого
[
\pi_j(c)\neq0,
]
где
[
\pi_j\colon G\twoheadrightarrow\mathbb Z/2^{e_j}\mathbb Z
]
есть проекция на (j)-й сомножитель. Положим
[
K=\ker\pi_j.
]
Тогда
[
c\notin K,
\qquad
G/K\cong\mathbb Z/2^{e_j}\mathbb Z,
]
то есть (G/K) циклична.

Так как (C) имеет класс (3),
[
[\gamma_3(C),C]=\gamma_4(C)=0.
]
Следовательно,
[
G=\gamma_3(C)\subseteq Z(C),
]
и потому любая его аддитивная подгруппа, в частности (K), является идеалом кольца Ли (C).

Положим
[
D=C/K
]
и обозначим образ (c) через (d). Тогда:

1. (D) конечно и (2)-примарно;

2. по функториальности
   [
   d\in\delta_5(D);
   ]

3. (d\neq0), поскольку (c\notin K);

4. поскольку (K\subseteq\gamma_3(C)),
   [
   \gamma_3(D)
   ===========

   # \frac{\gamma_3(C)+K}{K}

   \frac{G}{K},
   ]
   и эта группа циклична;

5. (\gamma_4(D)=0), а (0\neq d\in\gamma_3(D)), поэтому (D) имеет класс ровно (3).

Итак, мы получили конечное (2)-примарное кольцо Ли (D) класса нильпотентности (3) с циклической (\gamma_3(D)), причём
[
0\neq d\in\delta_5(D).
]
Это противоречит предположению, что для всех таких (D) выполнено (\delta_5(D)=0).

Следовательно, для всякого кольца Ли (L)
[
\boxed{\delta_5(L)\subseteq\gamma_4(L)}.
]

Вся редукция имеет вид
[
L
\supseteq A
\twoheadrightarrow
B=A/\gamma_4(A)
\twoheadrightarrow
C=B/2^NB
\twoheadrightarrow
D=C/K,
]
причём выбранный элемент на каждом шаге остаётся ненулевым и остаётся в (\delta_5). Равенство (\delta_3=\gamma_3) помещает его в центральную группу (\gamma_3), включение (2\delta_4\subseteq\gamma_4) делает его элементом порядка (2), а центральность (\gamma_3) позволяет затем факторизовать её до циклической группы.
